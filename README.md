# LangOS
Mini bureau Godot : menu Démarrer, Bloc-notes, clavier visuel, paramètres, système, mises à jour.
- Linux : `curl -fsSL https://github.com/goodview-soft/LangOS/releases/latest/download/install.sh | sh`
- Android : [BlocNote.apk](https://github.com/goodview-soft/LangOS/releases/latest/download/BlocNote.apk)
- Publier : `./release.sh 1.0.0 "notes"`

## Données
Dictionnaires : [FreeDict](https://freedict.org) (licences GPL / CC, voir chaque dictionnaire), générés par `tools/build_dicts.py`.
